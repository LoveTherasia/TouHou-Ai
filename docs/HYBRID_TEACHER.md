# 力场先验 + 分数重排: hybrid 老师

> 状态：**实现完成、可用，但没有打赢 rule-DAgger**。这份文档记录设计、实测数字，
> 以及四个**已经量过的负面结果**——不要再重复踩。
> 时间：2026-10-21。相关代码：`training/{hybrid_teacher,score_teacher,rule_teacher}.py`、
> `tools/pattern_bench.py`。

## 0. 一句话

把"规则老师的力场"当**安全先验**、把"奖励权重"当**排序目标**、把"安全阈值"换成
**连续屏障**，得到的三合一老师本身是全场最强的玩家（**4770 步 / 8617 伤害 / 89% 对准**，
规则老师 3501 / 5344 / 78%），但**蒸出来的学生比从规则老师蒸的差**
（2469 vs 3521 步）——"老师更强"不等于"学生更强"。

## 1. 为什么需要一个新老师

| 老师 | 优点 | 致命缺点 |
|---|---|---|
| `rule_teacher` | 标签**好模仿**（力场只看身边几十像素的弹幕，空间平滑） | 不会算分，只有一条硬编码的"朝 Boss 归位" |
| `score_teacher` | `score_scale` 真的进决策（改权重就改标签） | 9 路 argmax + 硬阈值，标签在阈值附近跳变，蒸馏效果差 |

hybrid 想同时拿到两边的好处。

## 2. 设计（三个加性项）

对 9 个方向各做时间展开，取

```
value = attack − danger − barrier + prior
```

| 项 | 公式 | 作用 |
|---|---|---|
| `attack` | `(score_scale + boss_damage_scale) × score_rate × 对准帧数` | 攻击意图；`score_rate=4`/帧（mock 实测）、`align_tol=20px` |
| `danger` | `danger_scale × (1 − clearance/danger_radius)` | 轻量斥力（辅助，不再是主导项） |
| `barrier` | `barrier_weight × (1 − clearance/safety_margin)²`（仅 clearance<margin） | **连续**的生存约束：0px→25、6px→6.3、12px→0 |
| `prior` | `prior_weight × max(0, cos(方向, 力场方向))` | 力场先验：说往左则左=2.5、左上=1.77、右=0 |

`prior` 直接调用 `RuleTeacher.force_vector()`，**与 rule 老师同源**：改力场，两个
老师的标签一起变（`tests/test_hybrid_teacher.py::SharedForceFieldTest` 锁死）。

量级关系（默认 `prior_weight=2.5 / barrier_weight=25`）：满对准 22 帧 ≈ **11.4**，
贴脸屏障 **25**、真实掉残 **−200**。所以"能对准就对准、但不值得用命换"。

**为什么用连续屏障替掉硬阈值**：硬阈值让"间距 11.9 与 12.0"这两个几乎相同的局面
产生相反的标签，这是 argmax 老师难模仿的直接原因之一。

## 3. 四个负面结果（都量过，别再试）

| 尝试 | 结果 | 结论 |
|---|---|---|
| 收益窗口拉到 **60 帧**（想让"走过去对准"更值） | 老师存活 4770 → **1350** | 长收益窗口 = 只顾对准、看不见远处弹幕 |
| 屏障从 25 提到 **100**（更保命） | 老师存活 4770 → **3067** | 屏障过强会被一路赶进角落 |
| **对所有弹幕**做 45 帧长时预测 | stage1 存活 4770 → **2971** | 弧线/反弹弹的虚假危险淹没了真信号 |
| 加**贴边惩罚**（margin 24 / weight 2.0） | stage1 存活 4770 → **2650**，对整齐升到 95% | 变成"为了不贴边而站在弹道里" |

贴边项与长时预测的代码都保留了（`edge_weight` / `wall_horizon`，默认关闭），
因为它们在"被墙挤到角落"的专用场景仍有价值，但**不要默认开**。

## 4. 蒸馏结果

同一套超参（`danger-grad / no-focus / step_frames=1 / 256×256 / teacher_epochs=12 /
danger_weight=3`），只换老师；贪心 12 局：

| 策略 | 存活步 | Boss 伤害 | 对准率 | 过一面 |
|---|---|---|---|---|
| 规则老师（参考） | 3501 | 5344 | 78% | — |
| rule-DAgger R2（基线） | 3521 | 5476 | 80% | 12/12 |
| **rule-DAgger R2 + PPO（修复后）** | **3905** | **6274** | 77% | 12/12 |
| hybrid-DAgger R1（120 局） | 910 | 648 | 43% | 2/12 |
| **hybrid-DAgger R2（+100 局）** | **2469** | **3964** | **90%** | 12/12 |
| hybrid-DAgger R3（+100 局） | 1443 | 1940 | 88% | 11/12 |
| hybrid-DAgger R3 + PPO | 1667 | 2387 | 88% | 10/12 |

结论：
1. **老师更强 ≠ 学生更强**。hybrid 老师 4770/8617/89%，但从它蒸出的最好成绩是 2469/3964。
2. R1→R2 提升巨大（910→2469），R2→R3 反而回退：**轮次不是越多越好**，R2 是这份
   超参下的拐点，再训会过拟合到"老师的当前行为"。
3. PPO（修复后）确实是正增益：`hybrid R3 1443 → 1667`、`rule R2 3521 → 3905`。

## 5. 弹型基准：真正的问题在哪里

新工具 `tools/pattern_bench.py`（固定种子、按弹型分别报均值/最差/死亡数）：

```powershell
python tools\pattern_bench.py --policy .runtime\policies\attack_ppo_fixed.npz `
  --seeds 3 --max-steps 2000 --bullet-velocity --danger-grad --no-focus
```

| 弹型 | attack_dagger_r2 | **attack_ppo_fixed** | hybrid_dagger_r2 |
|---|---|---|---|
| aimed_single | 2000 | 2000 | 2000 |
| aimed_spread | 2000 | 2000 | **922** |
| fan | 2000 | 2000 | **1273** |
| spiral | 2000 | 2000 | 1753 |
| dense_ring | 2000 | 2000 | **848** |
| ring_gate | 2000 | 2000 | 2000 |
| closing_ring | 2000 | 2000 | 1336 |
| **wall_gate** | **662** | **814** | **557** |
| 平均 | 1833 | **1852** | 1336 |

（上限 2000 步；数字是该弹型 3 个种子的均值）

三个可以写进结论的事实：

1. **躲避能力其实不弱**：`attack_ppo_fixed` 在 8 种弹型里 7 种撑满上限，对准 90~97%。
2. **唯一的硬失败是 `wall_gate`**（3/3 种子死，662~814 步）。它不是"躲得不好"，
   而是"来不及占位"：墙每 55 帧一堵、从 y=108 落到自机高度要 ~150 帧，缺口位置
   每堵横移 17%，**必须提前横向站位**。
3. **上限在老师身上**：让五个老师亲自打 `wall_gate` ——
   `rule_force 662 / rule_horizon 818 / gap 656 / score 914 / hybrid 546`。
   学生 662~814 已经贴着老师的天花板，**再训学生没有意义**。

## 6. 墙前瞻（opt-in，默认关）

只对"匀速直线弹幕墙"做 60 帧长时预测（`wall_horizon=60`），并假设"冲一段
（26 帧）后重新决策"而不是"一直朝一个方向走 60 帧"：

| `wall_horizon` | stage1 存活 | stage1 对准 | wall_gate 存活 |
|---|---|---|---|
| 0（默认） | **4770** | 89% | 546 |
| 60 | 3813 | 68% | **1320** |
| 90 | 3292 | 69% | 997 |

即"用 20% 的普通弹型存活换 2.4 倍的墙存活"。**而且直接拿来蒸馏会崩**：
在 `attack_ppo_fixed` 上用这个老师微调 100 局 → 平均存活 1376（原 1852），
`wall_gate` 621（没有变好），对准率掉到 54%。

结论：墙的能力**不能靠混合蒸馏获得**，需要单独处理（见下）。

## 7. 下一步

1. **`wall_gate` 要独立解**：老师层面要么做真正的"缺口搜索 + 提前占位"
   （现在只是"长时预测 + 最近间距"），要么让 PPO 在 `wall_gate` 上从零探索
   （奖励里 `miss_penalty=-200` 已经足够强），再与通才策略做**分层/切换**。
2. **验收改用弹型基准**，不要只看单面存活帧数——单面 3905 步掩盖了 `wall_gate` 662 步。
3. **对准率纳入验收**：hybrid-DAgger R2 的对准 90%+ 反而是**过度对准**的证据
   （`aimed_spread` 从 2000 掉到 922）。健康区间目前看是 77~80%。
4. hybrid 老师保留为**工具**（`--teacher hybrid`），不作为默认蒸馏来源；
   先修好"老师更强→学生更强"这条因果，再回来用它。
