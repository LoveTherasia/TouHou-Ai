## 2.6 能力边界：三种方法各缺什么（2026-10-21 实测）

用 `tools/climb_probe.py` 在 5 个弹型上量"最高点 `min_y`（场地 448，起点约 416）"
与"停留在上半场的帧数"——**这是判断"会不会主动上穿"的硬指标**：

| 方法 | aimed_single | dense_ring | ring_gate | closing_ring | wall_gate |
|---|---|---|---|---|---|
| k_bullets 策略（存活步） | 2000 | 2000 | 2000 | 2000 | **887** |
| k_bullets 最高点 min_y | 345 | 368 | 367 | 326 | 367 |
| k_bullets 上半场帧数 | **0** | **0** | **0** | 61 | **0** |
| gap822 策略（存活步） | 339 | 164 | 274 | 190 | 135 |
| 规划器（存活步） | 1200 | 1200 | 1200 | — | — |
| 规划器 min_y | 294 | 385 | **44.6** | — | — |
| 规划器上半场帧数 | 27 | **0** | **581（连续 355）** | — | — |

三条边界：

1. **k_bullets + 斥力：会躲不会穿。** 五个弹型 `min_y` 全在 325~368、上半场帧数
   0~61 —— 行为上限是"贴着下半区横移"。普通环/连发靠横移能活满 2000 步，
   但 `wall_gate` 887 步就死（需要提前横向占位）。
2. **gap：会找缺口，不会做 1 帧微调。** 单颗自机狙 468~2022 帧（反应式策略
   6000），结构性原因是：6 帧宏动作（一步 26px）、32 列 1D 剖面把 2D 问题压平、
   标签上限是手写策略。它训出来的策略换到 mock 弹型上还更快死（135~339 步），
   因为分布只在 replay。
3. **规划器：唯一会真上穿的，但看不到未来、且难蒸馏。** `ring_gate` 上它会一路
   爬到 `min_y=44.6`、连续 355 帧待在上半场穿过缺口；但它视界 200 帧、
   看不见"之后才生成"的弹，所以在真实长回放上只有 6 820 帧（hybrid 31 684）。
   把它当老师蒸馏，学生均 2 330 帧且 **86~92% 时间贴角**；加难数据纯模仿 325 局
   卡在 3 000 步 = 老师上限（15 424 帧）。

**所以三者不是替代关系，而是互补关系** —— 这也是分层切换能让 8/8 弹型满 2000 的唯一
原因：规划器负责"上穿/占位"，策略负责"单弹/连发的 1 帧反应"。

### 2.8 MPC 路线的三条实测（2026-10-22 追加，详见 `PLANNER_V2.md` §8）

1. **缺口项按"可达性"写是无效的**：`wall_gate` 的墙要 146 帧才落到自机高度，远长于
   72 帧视界，于是每个候选终点的"剩余时间"都很大，代价地形平坦（1144 步，权重
   2/6/15/40 全一样）。必须改成"**锚点** = 最近一堵墙的缺口中心列"。
2. **MPC 的步长可以粗，距离判定不能粗**：只在采样时刻算距离会穿透（弹每步 23px、
   判定直径 10px）。改成连续时间最近接近距离后，`wall_gate` h180/dt12 从 **648 → 1042**，
   而短视界反应式弹型一步不掉。
3. **真机轨迹是动力学模型唯一的养分**：mock/replay 全是匀速直线（残差恒 0）；
   75 秒真机采样（844 条 / 11.7 万点，29.4% 的轨迹在弯）训出的残差模型
   **MAE 1.899 → 0.844 px**（10 帧 3.92 → 1.40，好 2.8 倍）。

另有两个"当老师时的静默错位"必须记住：动作名要用 `up_left` 而不是 `up+left`；
`step_frames>1` 时自机速度与弹速都要按 k 换算，否则存活从 800 掉到 140。

4. **MPC 当老师蒸馏在 120 局规模上不成立**：老师自一致率仅 **21%**、相邻帧 50~77%
   换动作（CEM 在"多个动作同样安全"时随机 argmax）。学生和老师的一致率 **19.9%** ≈
   噪声上限；存活 570~620 / 老师 1097（**52%~56%**）。软标签（逐动作代价 → 分布）
   只带来 +3%，换 822 维缺口观测反而降到 570。**要先让老师确定化，或改成蒸馏
   cost-to-go 而不是动作。**

### 2.9 老师确定化 + cost-to-go（2026-10-22 晚，详见 `PLANNER_V2.md` §10）

1. **老师确实能被"确定化"**：加"并列动作承诺"（`commit_steps`）后换向率
   **51.8% → 27.2%**；同时把代价口径从"该动作按满视界"改成"走这一步 + 接 CEM 剩余
   路径"，老师动作与 `argmin(cost)` 从 **48.9% → 100%** 对齐。（`tools/teacher_check.py`）
2. **但学生没有因此变好**：同口径 5-seed 贪心评测（软标签控制组重测 **637 步**）下，
   cost-to-go 学生 **489（9 动作）/ 514（18 动作）**，且强弱分布变了
   （dense_ring/closing_ring 更好，ring_gate 从满 1200 掉到 ~500）。
3. **根因是"代价向量本身不连续"**：**74~78% 的帧里最优与次优代价完全相等**，
   其余动作相对代价 300+，除以 T=20 后全部撞 `clip=8`。目标实际只有 {0, −8} 两个值，
   回归退化成带并列的 one-hot —— 相对交叉熵没有优势。连"背下 2 局数据"都做不到
   （200 epoch 后 `argmin` 一致率仅 35%）。
   → 下一步必须**先给代价加平滑安全余量**（`mpc_smooth`，已实现），或改并列感知的
   排序损失；否则提高样本量无意义。
4. **focus（Shift 慢速）是这一轮唯一的质变**：带 focus 的 18 动作学生把
   `aimed_single` 从 **765 → 1200（5/5 满，伤害 1544）**。单颗自机狙要 2px 级半步，
   全速 8.8px/步踩不准。**真机训练必须开 focus，且先用 `tools/check_focus.py` 验证
   Shift 真的生效。**

### 2.10 并列感知排序 + focus：目前最好的一版（2026-10-22 深夜，`PLANNER_V2.md` §11）

1. **把"并列最优"当成一个答案**（`MLPPolicy.fit_rank`：并列组共享目标质量做 CE）
   比回归强得多：同 239 维观测、**70 局**（比回归少 50 局）拿到 **583** vs 回归 489；
   `rank_acc`（选中并列组内动作的比例）**21~26% → 70~74%**。
   成对 RankNet 不行：只拿 argmin 当正例会让并列组内 logits 被拉开 1.1。
2. **排序 + focus = 本轮最好：678（70 局，18 动作）**，首次超过软标签控制组
   （637，120 局，9 动作）。`dense_ring` 359→770、`ring_gate` 1200/807、
   `aimed_single` 满 1200。
3. **规划器同构的 822 维缺口观测没帮上忙**：拟合更贴（`rank_acc` 77~91%）但存活
   567 < 583，与 §2.8 的 BC5（822 维软标签 570）一致 —— 观测越大越难在小样本内学。
4. **继续训练不涨**（120 局 558 < 70 局 583）：更贴老师的代价 ≠ 更会活，因为老师代价里
   没有"对准/输出"项，越贴它越保守（对准率 2~19%）。下一步应在损失里补输出偏好。

### 2.11 planner_v2 方向复核：哪些对、哪些错、哪里断了（2026-10-22 收束）

详见 `PLANNER_V2.md` §12。一句话：**架构方向对，但"对"的范围比设计稿窄，且当前卡点不在算法。**

**被数据支持的 4 条（继续押注）**

1. 规划器确实是能力上限的好代理：6 弹型 bench **满 1200**，而反应式策略在 `ring_gate`/`wall_gate`
   上结构性失败；只有规划器能上穿（`min_y 44.6` vs k_bullets 325~368）。
2. **动作空间改动 > 算法改动**：`focus`（9→18 动作）带来的增益（`aimed_single` 765→1200、
   `dense_ring` 359→770）大于所有蒸馏损失改动之和。
3. **"并列"是这个问题的核心结构**：并列组 CE 让 `rank_acc` 21%→70%，且少 50 局就超过回归。
4. **学习型动力学在真机有真收益**：MAE 1.899→**0.844（44%）**，10 帧 3.92→1.40。这是 v2 唯一
   不可替代的部分（mock 匀速弹上恒为 0）。

**被推翻的 3 条（别再试）**

| 假设 | 数字 | 教训 |
|---|---|---|
| cost-to-go 连续价值可回归 | 74~78% 帧最优与次优严格并列，其余撞 `clip` → 目标只有 {0,−8}；489 < 软标签 637 | 老师的代价是**约束满足型**，不是优化型，里面没有连续价值 |
| 观测越像规划器越好（822 维） | 排序 822 维 567 < 239 维 583；BC5 也 570 | **信息量 ≠ 可学性**；观测规模要跟样本量走 |
| 局数越多越好 | 70 局 583 → 120 局 **558**（rank_acc 反升到 77%） | 老师本身有偏时，加数据 = 更彻底地学这个偏 |

**三个链路断点（决定了"v2 失败"这个判断暂不成立）**

1. **动力学没接进蒸馏**：`trainer.py` 构造 `MPCTeacher` 不传 `dynamics`、`mock_full_clear.py`
   无此参数 —— 老师一直用 `ConstantVelocity`，"学出来的模型参与规划"在产数据侧从未生效。
2. **老师的代价里没有"要打"（收束时实测，比原判断更严重）**：瞄准项写成
   `if raw["boss_position"]`，而 mock 里 **boss 第 292 帧才出场**（300 帧内可用率 3%）→
   `step_frames=2` 时前 ~146 决策步**完全没有瞄准项**；有 boss 时上界也只有 **3.5**，
   而安全项量级 200~**800**（差 60~230 倍）。**双重失效** → 纯躲避老师 → 对准率 2~19%。
   `PLANNER_V2.md` §5 风险 2 预警过，实现时没兑现。
3. **PPO 微调一次没跑**：§9~§11 全是 BC/DAgger。**678 是"模仿上限"，不是 M5 的验收结果**
   （门槛是 ≥ 老师 90% = 1080）。

**战略判断：mock 已经刷不出新信息**

老师已满分（1200 = bench 上限）、mock 全是匀速直线（M2 价值恒 0）、学生卡在"老师不完整"。
在 mock 上还剩两件有意义的事：**修老师代价**、**跑 PPO 微调**；其余刷分只会更贴一个不完整的老师。
真正该做的是**上真机一次**（`check_focus.py` → 带 focus 的 18 动作 × replay 弹幕）。


### 2.12 贴顶治理 + ListMLE + 位置正则（2026-10-22 收尾，`PLANNER_V2.md` §13）

1. **"贴顶"不是老师教的**：MPC 老师直跑 900 步，贴顶 **0%**、min_y 334~354；
   而学生贴顶 9%（`ring_gate` 29%）。**往上躲能减少可见弹量**，是学生模仿时的自发退化。
   → 位置偏好加在老师侧几乎无效，重心在学生侧正则。
2. **贴顶可以彻底压掉（→0%），但要收"存活税"（−37%~−50%）**。
   因为**贴顶本身是一种逃课**（越往上弹幕越稀）。把自机拉回中场 = 主动走进密集区。
3. **对准率可以提升 5 倍（7% → 32~34%）**，这是干净的正收益：回中场正好落在能打到
   Boss 的列上。
4. **单向正则是陷阱**：它让学生学会上穿（`ring_gate` 385 → **1200 满**），但没给
   "下来"的力，于是 78% 时间挂在天花板上 —— **分数最高、行为最差**。
   教训：`不往上 ≠ 往下`。必须**双向**（罚往外 + 奖回中场）。
5. **必须加行为诊断**：本轮给 `pattern_bench` 加了 `贴顶%` / `min_y`。
   没有它，第 4 条那种改动会被误判成成功。这是本轮最有复用价值的产出。
6. **tie-aware ListMLE 的两个实现坑**：① loss 对称 ≠ 梯度对称（`∂loss/∂s_t ∝ e^{s_t}`，
   并列组内梯度差 35 倍）→ 必须**组内梯度均摊**；② 稳定 lr 上限 ~1e-3（2e-3 会过冲
   后期退化）。修完并列组内 |Δlogit| 1.1 → 0.23。

**当前最平衡配置**：`--listmle --position-reg --position-reg-weight 0.5 --position-reg-pull 0.4
--mpc-commit-frames 12` → 429 分、**0% 贴顶**、32% 对准、`aimed_single` 满 1200。

### 2.13 拉到 200 局：续训有效、从零无效（`PLANNER_V2.md` §14）

1. **续训 200 局 463（+8%），从零 200 局只有 397（< 70 局的 429）**。同配置同数据量，
   差别只在起点 → 修正 §11.5"续训不涨"：**问题不是续训，是同 lr 跑太久会漂移**。
2. **真正的收益是伤害：246（基线）→ 442，达老师的 92%**；对准 7% → **35%**（5 倍）；
   贴顶 9% → **2%**。`wall_gate` 241→408、`closing_ring` 331→466（都是长视界弹型）。
3. **学生已经学会"打"，没学会"躲"**：老师存活 1200 满 / 伤害 479，学生 463 / 442。
   "躲"是模仿的天花板——老师用 72 帧视界 + 全场弹幕，学生只有最近 32 颗弹。
   **只有 RL 微调能用奖励直接优化这一项。**
4. **承诺期不能一味加长**：换向率 51.5%→13.1%（0→24 帧）单调下降，但
   **"动作≈当前帧代价 argmin"也从 100% 掉到 49%** —— 承诺期里老师执行的是旧方向，
   而标签每帧重算，二者越离越远。**8~12 帧是平衡点**（错位 27~39%）。

### 2.14 PPO 微调跑通：463 → 902 步（2026-10-23，`PLANNER_V2.md` §15）

1. **v2 的 RL 那半层第一次运行**（此前全是 BC/DAgger）。以 `lm200_cont` 为初始化，
   `multi` 奖励，无老师 → 自动进 PPO 分支。**存活 463 → 902（×1.95）、
   伤害 442 → 558（×1.26）、贴顶 2% → 0%**。学生伤害已超 MPC 老师（479）。
2. **PPO 的有效窗口只有 600~800 局**：最佳快照在 +600 局，之后持续苟化
   （伤害 558 → 277 → 114）。再续训反而降（902 → 842）。
3. **KL 锚适合"防崩"、不适合"求改进"**：锚 0.05 只有 508，无锚 740 ——
   把 PPO 拴在一个不够好的 BC 策略附近，收益上限就是 BC 水平。
4. **苟化的根因是奖励量级**：`alive_bonus 0.3×600步 ≈ 180` vs
   `progress 6×血量比 ≤ 6` + `damage 0.1×500 ≈ 50`，输出:存活 = 1:3~1:30。
   但一次改三个权重的 `multi_attack` 失败（692 / 218）—— **改奖励要一次只动一个旋钮**。
5. **对准率下降 ≠ 退化**：35% → 14% 但伤害上升，因为对准率是每步比例、伤害是累计量。
   **评测必须同时看存活/伤害/对准三个指标。**
6. **仍有一类弹型没解决**：`wall_gate` 408 → 328。墙需要"提前 60 帧横向占位"，
   反应式策略 + 即时奖励给不出这个信号。

**当前最强**：`.runtime/ppo_cont/policy_best.npz`（902 步 / 伤害 558 / 贴顶 0%）。
链条：MPC 老师 → ListMLE 蒸馏（`lm200_cont`）→ PPO 微调（`ppo_cont`）。

## 3. 已作废的结论（别再照着做）

| 曾经的结论 | 为什么作废 | 现在的正确说法 |
|---|---|---|
| **"PPO 必崩，RL 微调一定会毁掉 DAgger 成果"** | `_gae` 把价值又除了一次 `scale`；`load()` 用 checkpoint 的 lr=1e-3 覆盖命令行；`kl_anchor` 从磁盘直跑时恒为 0 | PPO 可用且能超过 DAgger。**KL 5.2 → 0.08**，value_loss 33 → 0.001 |
| **"k_bullets + 斥力就够用"** | 同屏 400+ 时只能看到 4~16%；GAP_LEARNING 已量过同一规则换观测 1182 → 2400 | 密弹必须用危险图/缺口；k_bullets 只适合稀疏弹型 |
| **"gap/TTA 是通用躲避策略"** | 它只表达"每车道最早到达时间"，无长程站位；60 局 gap 只有 6604 帧 | gap 是**墙/缺口的高层先验或辅助观测**，不能作唯一监督 |
| **"hybrid 老师最强 → 蒸馏出的学生最强"** | 老师 4770 步，学生 R2 只有 2469 步 | 老师强只保证标签质量；学生上限 = 老师，且常低于老师 |
| **"加贴角惩罚能治只躲不打"** | 贴角只是表征；根因是 `score` 项≈0、`danger` 一局扣 3306 | 2026-10-21 决策：**不做贴角惩罚**，改攻击配平 + 蒸馏加轮 |
| **"加大训练量就能突破老师"** | 加难数据纯模仿 325 局：ep100/250 卡在 3 000 步，ep300 才 3 765 步 = 老师 15 424 帧 | 纯模仿的硬上限就是老师；要突破必须让策略自己驱动 + 奖励有"对准"项 |
| **"换 `attack` 奖励档能修只躲不打"** | `attack` 档与当前默认配置**数值完全相同**（score 0.03 / danger 0.8 / alive 0.3…） | 换档等于没换。奖励里始终**没有"对准/输出"项** |
| **"回放脚本可以直接拿去复刻"** | 旧脚本 37% 弹速记为 0、2 686 条重复、且不记 despawn | 必须重录（v2）或在录制端补 `life` |
| **"所有老师都在 15k 帧统一死亡 = 老师不行"** | mock 的 `MAX_BULLETS=900` 把失真数据截成"恒定 900 颗静态弹海" | 是**数据损坏**；修好后 hybrid 直接 31 684 帧 |
| **"记录在损坏弹海上训练的策略，数字可以和干净环境横比"** | 那份环境根本不存在于真机 | 旧数字只能当历史；但意外发现它等价于**高难度课程**（见 §4.3） |

### 4.3 一个反直觉但成立的发现

**训练环境比评估环境难，策略就更稳。** 在"900 颗静态弹海"上训出来的 k_bullets
策略，到了干净环境里 5 起点平均 21 839 帧、单局 38 920 帧，比专门在干净数据上
训的 gap 策略（14 139）还强，甚至超过 hybrid 老师在 offset 0 的成绩。

→ 结论：**难度是资产**，加难数据应该按比例混进训练，而不是丢掉。
