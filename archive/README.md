# archive —— 非维护文件

这里存放的是**不属于构建、也不参与运行**的历史文件。可以随时整目录删除，
不影响项目功能。

- `root/` —— 曾经散落在项目根目录的残留文件
  - `hello.obj`：早期编译器/打包试验产物
  - `@AutomationLog.txt`：一次 UI 自动化尝试留下的 UIAutomation 报错日志
- `diag/` —— 从 `.runtime/` 里清理出来的 47 个一次性探针脚本
  （`_probe_*.py`、`_diag_*.py`、`_cmp_*.py`、`_menu_*.py` 等）。
  它们记录了当时的排查过程，但路径与假设都已过期，仅作参考。

`.runtime/` 现在只放**运行产物**（训练输出、日志、截图、录制的弹幕脚本），
不再混入源码。
