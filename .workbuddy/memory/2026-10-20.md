# 2026-10-20

## 缺口观测接进 Trainer + 换奖励 + 换标签（v2）

- **接入**：`TrainConfig` 新增 `use_gap / gap_grid|geo|clearance / gap_prev_action /
  gap_label / scenario / scenario_random`；`features.observation_dim`、
  `encode_observation(state, config, prev_action=)`、`ObservationEncoder` 全部支持缺口观测；
  `Trainer` 传递上一动作方向、每局应用/重采场景参数、支持 `teacher="gap|gap_dagger"`。
- **新文件**：`training/gap_label.py`（标签从实验脚本搬进包里，新增 `slack`）、
  `training/gap_teacher.py`（老师协议）、`tools/research/gap_trainer.py`（BC→DAgger→PPO
  分阶段 + 留出场景评估）、`tools/research/gap_report.py`（存活饱和时看飞行方式）。
  看板新增 `gap_trainer` 食谱。
- **修掉三个 bug**（每个都单独改变结论）：
  1. `GapObservation.__call__` 复用同一块缓冲区 → 轨迹里所有观测都是最后一帧。
     BC 有 `.copy()` 躲过，纯 RL 一直在用终局状态更新。改成每次返回新数组。
  2. TTA 剖面要求"车道中心落在 [x±5]"才判定威胁，而车道 12px、判定 5px → 落在两个
     中心正中间的弹（v2 每 4 颗一枚）**不可见**，占 27%。改成"车道区间与危险区相交"。
     v2 上 30 局 BC：748 → 1560 帧；DAgger：1300~2126 → 2400。
  3. PPO 的价值回归用原始回报（量级 1e3），平方损失冲垮共享隐层
     （value_loss 4618 / grad_norm 2626 / 熵→0），把 2400 的策略打回 624。
     `_update_ppo` 现在按整批回报量级缩放（对 GAE 线性，优势不变）。
- **结论**：v2 四组配置（旧/新奖励 × 旧/新标签）全部 2400×3/3，一致率 90~95%。
  **v2 已饱和**（规则缺口跟随能无限跑），奖励/标签只剩"飞行方式"上的小差异
  （势函数把横移占比 35%→44%，最近弹距 115→132px）。
- **标签口径**：`now/reach/slack` 在老师状态分布上 100% 相同；`slack` 的 dwell 项在
  固定周期的弹幕墙上逐列常数，"决定 argmax 的比例 = 0%"，结构性地无效。`future` 不同
  但偏好苟住（806 帧）。`now` 早先与 `reach` 相同是**代码 bug**（分支不可达），已修。
- **新增 `bench v3`**（interval 75 / drift 0.9 / width 44）：规则基线 ~1800，2400 不再是
  天花板。标定发现难度瓶颈是**赶路时间**（drift×360/4.4 超过 interval），不是缺口宽度
  （gap_width 46→30 仍是 2400）。**本轮未在 v3 上训练**。
- 测试 150 个用例（2 个因环境缺 `mcp` 包报错，与改动无关）。
