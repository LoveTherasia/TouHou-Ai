## 规划器 v2：Deep Sets / 多目标奖励 / 动力学 / MPC（用户指定方向）

设计文档 `docs/PLANNER_V2.md`；已实现 M1~M4，M5（蒸馏闭环）/M6（真机采集）待做。

- **Deep Sets 观测**（`features.py` 的 `use_set`）：逐弹 5 维 (dx,dy,vx,vy,ttc) → 固定
  随机投影 φ(5×32) → mean+max 池化 + 弹数 + 最近距离 = 66 维；置换不变、支持不定长、
  与 PPO 扁平输入兼容。测试 `tests/test_planner_v2.py`（5 例）。
  ⚠️ φ 是固定投影，端到端学 φ 需改策略结构（会破坏零初始化扩维契约）。
- **多目标奖励**（`rl/reward.py`）：新增 `progress_scale`（ΔBoss 血量比）与
  `position_scale`/`position_y_target`/`position_edge`（位置偏好：贴角 -0.61 vs 中间 -0.02）；
  新增 `multi` 档（存活+进度+分数+位置）。config.py/config.json 同步 4 个键。
- **动力学模型**（`training/dynamics.py`）：残差 MLP，特征必须含**加速度**
  (x,y,vx,vy,ax,ay,dt)——只给速度时残差 0.5at² 不可预测，模型学不动（实测 MAE 6.7 比
  匀速 5.7 还差）。加加速度 + Adam 后：合成加速弹 MAE 0.20px vs 匀速 5.73px（30 帧
  预测 124.15 vs 真值 124.0）。mock 弹是匀速直线 → 残差恒 0，没有可学的。
  工具 `tools/train_dynamics.py`（--script/--tracks）。
- **MPC/CEM**（`training/mpc.py`）：CEM 采样 2D 速度序列，代价=安全余量²+碰撞硬罚+
  对准+站位；每步只执行首动作。实测（6 弹型，2000 上限）：短视界 24 帧均 1755
  （wall 548）；长视界 72 帧+缺口项均 1359（wall 1152，但 spread 922/ring 1219/
  closing 862）；**自适应（按 WallDetector 切视界）均 1858、5/6 满 2000、wall 1150**；
  单步 1~15ms（viability 25~40ms）。
- **势能场**（`training/potential.py`）：φ=Σexp(-d²/2σ²)+边界+站位，9 邻域负梯度 +
  滞回；均 1416、wall 1162、对准 3~5%（只能当兜底）。
- 基准接入：`pattern_bench.py --policy mpc|mpc-adaptive|potential`，
  新增 `--mpc-horizon/--mpc-dt/--mpc-samples/--mpc-iters/--mpc-clearance/--mpc-column`。
- 结论：**长短视界互相伤害** → 视界要随局面切换；MPC 快但墙不如 viability 的 DP，
  下一步把"缺口中心+到达时间"显式接进 MPC 代价。

## 规划器 v2 收尾：M4 修复 / M5 蒸馏 / M6 真机轨迹（2026-10-22 下半段）

### M4 三个坑（都实测过，结论可能反直觉）

- **缺口项按"可达性"无效**：wall_gate 的墙要 146 帧才落到自机高度 > 72 帧视界，
  所有终点 slack 都很大 → 代价平坦（1144 步，权重 2/6/15/40 全一样）。
  改成**锚点** `|x_end − x_gap|/384`（缺口中心，要求同刻 ≥8 颗且封 ≥50% 列）；
  锚点必须瞄**视界之外**最近那堵墙（瞄最早一堵时目标每次突跳 61px）。
  结果 1028~1090，改善有限。
- **粗步长会穿透（真 bug）**：dt=12 时弹每步 23px、判定直径 10px，采样点全落在空隙里。
  改成**连续时间最近接近距离**（二次式）：wall_gate h180/dt12 **648 → 1042**，
  短视界反应式弹型一步不掉。**步长可以粗，距离判定不能粗。**
- **老师适配两个静默错位**：动作名要 `up_left`（MPC 出 `up+left` → `_teacher_index`
  解析失败全落 0）；`step_frames>1` 要同时缩放自机速度与弹速（否则 800 → 140 步）。

### M6 真机轨迹 + 动力学（首个真实收益）

  跳变 30px 断轨，中心/二阶差分出 v/a。真机 75 秒 → **844 条轨迹 / 117124 点**，
  29.4% 的轨迹明显弯曲（>0.5°/帧）。
- `train_dynamics.py --tracks`：匀速 MAE **1.899px** → 残差 MLP **0.844px**（44%），
  10 帧 3.92 → 1.40。mock/replay 上残差恒 0（都是匀速直线）。
- 已接进规划器：`pattern_bench --mpc-dynamics ...`；在 mock 上不损伤。

### M5 蒸馏：结论是"这条路在 120 局规模不成立"

- 老师（自适应 h72+锚点20）同循环 6 弹型平均 **1097** 步（5/6 满 1200，wall 581）。
- BC1 硬标签 596 / BC2 加承诺期 601 / BC4 软标签 619 / BC5 缺口观测+软标签 570。
  → 稳定在老师的 **52%~56%**。
- **根因（量化）**：老师自一致率只有 **21%**，相邻帧 50~77% 换动作（并列动作随机 argmax）；
  学生一致率 19.9% ≈ 噪声上限。CEM **热启动**（上一步精英均值）把抖动 77%→50%，
  但自一致仍 ~25% —— 抖动是表象，并列动作才是本质。
- 实现了软标签蒸馏全链路（`MPCPlanner.action_costs/soft_labels`、
  `Trajectory.soft`、`MLPPolicy.imitate_batch` 支持 (N,A) 目标、`--soft-labels/--soft-temp`），
  只换来 +3%，说明**样本量也不是唯一瓶颈，映射本身难拟合**。
- 下一步优先级：①老师确定化（iters↑/固定种子/并列动作承诺）②蒸馏 cost-to-go
  而不是动作 ③局数 500+ 或只在墙/收网局面采样。
- 文档：PLANNER_V2.md §8-9、CONCLUSIONS.md §2.8。测试 319 通过（2 跳过），ruff 0。

## 收尾：贴顶治理 + 承诺期按帧 + tie-aware ListMLE + 位置正则（PLANNER_V2 §13）

- **核心发现：贴顶不是老师教的**。MPC 老师直跑 900 步贴顶 **0%**、min_y 334~354；
  学生贴顶 9%（ring_gate 29%）。学生把"上穿"这个局部手段当成了长期策略（往上=可见弹更少）。
  → 老师侧位置偏好几乎无效，重心在学生侧正则。
- 新增 `mpc.py`：`top_weight/top_margin/bottom_weight/edge_weight` 持续贴边租金（二次、逐步平均，
  与视界长度无关，允许上穿但要付租金）；`MPCTeacher.commit_frames` 按游戏帧给承诺期。
- 新增 `MLPPolicy.fit_listmle`（tie-aware ListMLE，按组连乘）+ `_backprop_logits`。
  **两个坑**：① loss 对称 ≠ 梯度对称（梯度 ∝ e^{s_t}，并列组内差 35 倍）→ 组内梯度均摊，
  修后 |Δlogit| 1.1→0.23；② 稳定 lr 上限 1e-3（2e-3 过冲，500 步退化到 0.77）。
- 新增 `Trainer._position_reg`（学生侧双向正则，pull 负权重=奖回中场）、`Trajectory.posreg`。
- 新增诊断：`EpisodeRecord.top_ratio/min_y/mean_y` + `pattern_bench` 输出 `贴顶%/min_y`。
  **这是本轮最有复用价值的产出**——没有它会把"分数涨、行为坏"的改动误判成成功。
- 实测（70 局/900 步/6 弹型）：基线 678/贴9%/对准7%；无正则 442/0%/13%；
  单向w2 504/**21%**/4%（ring_gate 1200 但贴顶 78%）；双向w1 339/0%/**34%**；
  **双向w0.5/p0.4 429/0%/32%（最平衡，aimed_single 满 1200）**。
- 结论：贴顶能压到 0%，但收 −37%~−50% 存活税（贴顶=逃课，回中场=走进密集区）；
  对准率是干净正收益（5 倍）。`不往上 ≠ 往下`，必须双向。
- 测试 333 通过（2 跳过），ruff 0。
